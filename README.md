# AutoHub Updates

Este repositório está reservado para os arquivos e metadados de atualização do aplicativo AutoHub.

## Estado atual

O repositório não contém executáveis, releases, feed ou manifesto de versões. Portanto, ainda não distribui atualizações automáticas e não define um formato de atualização.

## Ferramentas e versões

Não há ferramenta de empacotamento, workflow de publicação ou versão do aplicativo declarada aqui. Esses detalhes deverão ser documentados quando o canal de atualização for implementado.
